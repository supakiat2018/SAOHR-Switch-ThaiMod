## 📖 สรุปภาพรวมม็อดภาษาไทย

ม็อดภาษาไทยสำหรับ **Sword Art Online: Hollow Realization Deluxe Edition** บนเครื่อง **Nintendo Switch** พอร์ตมาจากม็อดภาษาไทยเวอร์ชัน PC โดยแก้ปัญหาความเข้ากันได้ทางสถาปัตยกรรมระดับฮาร์ดแวร์และการ์ดจอ (Nvidia Tegra X1) โครงสร้างตารางฟอนต์ของเอนจิ้นเกม (PhyreEngine) และผังฟอนต์ UI (.S2D) ทั้งเกม 100% จนสามารถแสดงผลภาษาไทยได้คมชัด สวยงาม ทึบสีขาว มีหัว และสระวรรณยุกต์ถูกต้องสมบูรณ์แบบ

### จุดเด่นของเวอร์ชันนี้
* **ไฟล์ที่ต้องใช้:** `usa.cpk` (ขนาดประมาณ 787 MB) **ไฟล์เดียวเท่านั้น!**
* **ไม่ต้องใช้ `data.cpk` (13 GB):** ช่วยประหยัดพื้นที่เมมโมรี่ และตัดปัญหาเกมเด้ง/แคชค้างบนเครื่อง Switch และอีมูเลเตอร์ Ryujinx ได้ 100%
* **ชี้ฟอนต์ไทย `font00` ครบ 100%:** แก้ไขไฟล์เลย์เอาต์เมนู UI (`.S2D`) ทั้งหมด 49 ไฟล์ รวม 1,152 เฟรม ให้เรียก `font00` หมดทุกจุด ทำให้ขีดเส้นใต้ `____` ในหน้าตั้งค่า (Option) และทุกหน้าต่างหายไป 100%
* **แปลเนื้อหาภาษาอังกฤษที่ตกหล่นเพิ่ม 108 จุด:** รวบรวมข้อความที่ม็อด PC เดิมปล่อยเป็นภาษาอังกฤษ มาแปลไทยและเข้ารหัส CJK ฟอนต์ลงใน `localize_msg.dat` ผ่านตาราง `untranslated_108_thai.csv`
* **เนื้อหาที่แปลเป็นภาษาไทย:**
  * บทสนทนาเนื้อเรื่องหลักและเนื้อเรื่องรอง (DLC ทั้งหมด)
  * เมนูคำสั่ง ป๊อปอัปแจ้งเตือน ระบบเซฟ คำอธิบายภารกิจ
  * รายละเอียดไอเทม อาวุธ ชุดเกราะ สกิล และคำอธิบายระบบเกมทั้งหมด

## 🔬 รายละเอียดทางเทคนิค & ต้นตอการแก้ไข (Technical Breakdown)

### 1. ระบบฟอนต์ในเอนจิ้น PhyreEngine & การจัดสรรรหัสตัวอักษร
* เอนจิ้น PhyreEngine ของเกมนี้ ทั้งบน Switch และ PC **ไม่มีช่วงรหัสภาษาไทย (`0x0E00 - 0x0E7F`) และไม่มีช่วง PUA (`0xE000+`)** บรรจุในตารางฟอนต์
* ตัวม็อดภาษาไทยใช้เทคนิค **แทนที่ช่วงตัวอักษรจีน (CJK Unified: `0x4E00 - 0x9FFF`) ทั้งหมด 3,009 ตัวอักษร** โดยนำภาพ Glyph ตัวอักษรไทยไปแมปใส่ในช่องรหัส CJK
* ข้อความภาษาไทยทั้งหมดใน `msg/localize_msg.dat` จึงถูกเข้ารหัสเป็นอักขระ CJK ที่สอดคล้องกับภาพในตารางฟอนต์

### 2. การแก้ปัญหาพิกเซลขาดเป็นเส้นลวด (Tegra Block-Linear Swizzle Bug)
* **ปัญหาเดิม:** ตัวอักษรไทยขาดเป็นริ้วแนวนอน 4 พิกเซล และข้างในกลวงเหมือนเส้นลวดโปร่งแสง
* **สาเหตุ:** การ์ดจอ Nintendo Switch (Nvidia Tegra X1) จัดเก็บรูปภาพแบบ Block Linear (GOB Tiling: 64x8 ไบต์) โค้ดเดิมมีการสลับบิตที่ 7 กับบิตที่ 8 ในฟังก์ชัน `get_gob_offset`:
  * บิต 7 ควรเป็นแกน Y (`(y >> 2) & 1`) มีน้ำหนัก 128
  * บิต 8 ควรเป็นแกน X (`(x >> 5) & 1`) มีน้ำหนัก 256
* **การแก้ไข:** แก้ไขสูตร Bit Address ตามคู่มือ TRM ของ Nvidia Tegra X1 (`tools/tegra_swizzle.py`):
  ```python
  def get_gob_offset(x, y):
      return (
          (x & 0x0F) |
          ((y & 1) << 4) |
          (((x >> 4) & 1) << 5) |
          (((y >> 1) & 1) << 6) |
          (((y >> 2) & 1) << 7) |
          (((x >> 5) & 1) << 8)
      )
  ```
  ผลลัพธ์: ตัวอักษรและพิกเซลทั้งหมดกลับมาคมชัด 100% ขาวทึบ มีมิติขอบเงาถูกต้อง

### 3. การแก้ปัญหาสัญลักษณ์ขีด/ข้อยกเว้น (`≒`) ด้วยโครงสร้าง Glyph 45 ไบต์เต็ม
* **ปัญหาเดิม:** ตัวอักษรบางตัว (เช่น `ย`, `เก`, `ติ`, `ว`, `บ`, `นั`) แสดงเป็นสัญลักษณ์ข้อยกเว้น (`≒`)
* **สาเหตุ:** ตาราง Glyph แต่ละตัวใน `font00.fgen.phyre` มีความยาว **45 ไบต์**:
  * ไบต์ 19–43: พิกัดภาพ (UV Bounding Box: X, Y, Width, Height)
  * **ไบต์ 0–18 และ 43–45: Advance Width (ระยะเคาะเลื่อนไปตัวถัดไป), Bearing X/Y, และ Flags**
  * สคริปต์รุ่นแรกคัดลอกเฉพาะพิกัดภาพ (ไบต์ 19–43) ทำให้ระยะ Advance Width ไม่ตรงกับขนาดตัวอักษรไทย เอนจิ้นเกมจึงมองว่าขนาดผิดปกติและดีดสัญลักษณ์ Fallback (`≒`) ขึ้นมา
* **การแก้ไข:** ปรับปรุง `build_saohr_switch_font.py` ให้คัดลอกข้อมูลโครงสร้างแบบ **45 ไบต์เต็ม 1:1 ครบทั้ง 3,009 ตัวอักษร** ทำให้ทั้งภาพและระยะเคาะไฟสระ-พยัญชนะถูกต้องสมบูรณ์แบบ

## 🚀 วิธีการติดตั้งใช้งาน

### วิธีที่ 1: ติดตั้งบน Nintendo Switch จริง (Atmosphere CFW)
1. เชื่อมต่อ microSD card ของ Nintendo Switch เข้ากับคอมพิวเตอร์ (หรือผ่าน DBI / MTP Responder)
2. ก๊อปปี้ไฟล์ `usa.cpk` ไปวางไว้ที่โฟลเดอร์ปลายทาง:
   ```text
   sdmc:/atmosphere/contents/0100EC400D54E000/romfs/pkg/usa.cpk
   ```
3. นำ microSD เสียบกลับเข้าเครื่อง Switch แล้วเปิดเกมเล่นได้ทันที!

### วิธีที่ 2: ติดตั้งบนโปรแกรมจำลอง Ryujinx (PC)
1. เปิดโปรแกรม **Ryujinx**
2. คลิกขวาที่เกม **Sword Art Online: Hollow Realization** ➔ เลือก **Open Mods Directory**
3. สร้างโฟลเดอร์ย่อยตามโครงสร้างนี้:
   ```text
   MODTH\0100EC400D54E000\romfs\pkg\usa.cpk
   ```
4. วางไฟล์ `usa.cpk` ลงในโฟลเดอร์ `pkg`
5. เปิดเกมใน Ryujinx เล่นภาษาไทยได้ทันที!
